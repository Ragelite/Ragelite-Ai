what it is

One platform.
Two intelligent roles.

Ragelite brings the full AI research lifecycle — from raw data to deployed experiments — into a single, role-based Java application.

Admin Control

Full platform governance — manage users, allocate compute resources, oversee research projects, and monitor usage across the organization.

Researcher Space

A focused lab — upload datasets, configure training runs, track experiments, and collaborate with team members seamlessly.

JDBC Persistence

Every record — users, datasets, training logs, experiment results — stored reliably in MySQL through clean JDBC database classes.

Multithreaded Engine

Training jobs run on background threads via Java concurrency — the UI stays responsive while heavy computation happens in parallel.

build roadmap

7-day sprint.
One week to ship.

A structured execution plan — from database schema to a polished, submission-ready application.

Day 1
Foundation — Schema + Setup
MySQL tables: users, projects, datasets, experiments, resources. Java project structure, packages, Swing login screen.
Day 2
OOP Core — 10 marks locked
Abstract User class → Admin + Researcher subclasses. Interfaces defined. Exception handling wired throughout.
Day 3
Admin Dashboard — Full CRUD
User, Resource, and Project management tables. JDBC connected and fully functional.
Day 4
Researcher Dashboard
Dataset upload/manage, experiment tracking, collaboration panel, profile management form.
Day 5
Collections + Multithreading — 10 marks
ArrayList & HashMap stores. SwingWorker for background training simulation. Synchronization implemented.
Day 6
Polish + DB Classes
All database classes finalized. Robust error handling on every JDBC operation. UI cleaned up.
Day 7 — Submit
Testing + GitHub + Submission
Full functionality test, edge-case fixes, GitHub repo finalized, PPT deck ready, submission form submitted.
